# About Me — Web Dev 1 Project

[![Netlify Status](https://api.netlify.com/api/v1/badges/0f115d20-58bf-4274-90d6-1166648dc569/deploy-status)](https://app.netlify.com/projects/about-me-amatoluke11-lgtm/deploys)

## Description

This project is a personal "About Me" website built from scratch as the core ongoing assignment for Web Development 1 at Raritan Valley Community College, Spring 2026. The goal was to design and deploy a fully functional, styled, and responsive personal website, learning and applying web development skills at each stage of the project.

Over the course of the semester, the project grew from a basic HTML file into a large, deployed website with multiple sections, a custom color scheme, responsive layout, embedded media, a contact form, and a navigation bar. Each assignment phase introduced new concepts that were immediately applied to this project.

---

## Color Scheme

The site uses a bold, high-contrast three-tone palette.

| Role | Color Name | Hex | RGB |
|---|---|---|---|
| Background | Mint Green | `#0AFC93` | `rgb(10, 252, 147)` |
| Text / Navbar / Accents | Bright Purple | `#3F1EE6` | `rgb(63, 30, 230)` |
| Accent / Divider | Mellow Pink | `#E37971` | `rgb(227, 121, 113)` |

The mint green background and bright purple text were chosen for their high contrast ratio (greater than 4.5:1). I did this to easily fit the accessibility requirements. The salmon pink accent adds warmth and visual separation between sections.

## Sections

- **Nav Bar** — A small bar at the top of the page that directs you to each category. Taught me how to style one, use smooth scrolling, hover effects, and more media query skills. On mobile, this truncates to a basic hamburger menu.
- **Bio** — A personal introduction including my name, location, what I want to be doing, and a little more information af=bout my major and aspirations. I learned how to center text and implement basic spacing for a website.
- **Hobbies & Interests** — 7 hobbies with links for each providing a Wikipedia article to explain what they are. I learned how to implement links and add stylized bullet points. Underneath, is a caption including a short description of each hobby.
- **Gallery** — Three sections covering my main hobbies: fishing, guitar, and snowboarding. Each includes a personal photo, a short caption, and a linked location tag showing where each photo took place (other than guitar). I learned how to input images in an orderly fashion, while also adding figcaption links underneath.
- **Blog** - A personal excerpt explaining and showing what image hover effects are, and what they are useful for, 3 examples underneath, showcasing them (all my photos).
- **Contact** — A web form to get in touch, with name, email, and message fields.
